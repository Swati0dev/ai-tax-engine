# Tax AI Platform

A modular Next.js tax assistance platform for source-grounded Indian tax guidance.

## Current Phase

Phase 2: Project Scaffold and App Architecture.

The application scaffold is intentionally limited to route shells, shared types, and module boundaries. Tax knowledge content, database implementation, AI orchestration, and production deployment happen in later phases.

## Local Setup

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Validation Commands

```bash
npm run typecheck
npm run lint
npm run build
```

## Environment

Copy `.env.example` to `.env.local` when local secrets are needed. Database and AI provider values are placeholders until their later phases.
