# Specifications

This document describes the current features and goals of the AI Tax Engine.

## Current Project Scope
- AI-driven tax assistance platform for Indian Tax laws.
- Knowledge base integration for Section 80D, 24(b), GST, etc.
- Database integration using Prisma and Neon PostgreSQL.

## Upcoming Features (Gamification & Interactive UX)
- **Gamified Knowledge Base:** Interactive "Swipeable Cards" and tax scenarios replacing static text.
- **'Find My ITR' Wizard:** A game-like quiz to determine which ITR form a user needs.
- **Business Tax Calculator:** Expanding the current calculator to include structures like Proprietorship, LLP, and Pvt Ltd Company.
- **Step-by-Step Filing Walkthroughs:** Visual, board-game style progress trackers for ITR filing procedures.
- **Gamification Engine:** XP, badges, and progress tracking to make learning about taxes addictive.
