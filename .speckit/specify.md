# Specifications

This document describes the current features and goals of the AI Tax Engine.

## Current Project Scope
- AI-driven tax assistance platform for Indian Tax laws.
- Knowledge base integration for Section 80D, 24(b), GST, etc.
- Database integration using Prisma and Neon PostgreSQL.

## Upcoming Features
- Spec-Driven Development integration.
- Enhanced search capabilities for tax sections.
- User-friendly dashboards for tax planning.
