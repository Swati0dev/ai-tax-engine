# PHASE_2.md - Project Scaffold and App Architecture

Objective: Create the working Next.js foundation and confirm application architecture before feature implementation.

## Phase 2.1 - Initialize Next.js App

Tasks:

- Create a Next.js TypeScript project.
- Add basic routing and global layout.
- Add linting and formatting configuration.
- Add Tailwind CSS and shadcn/ui setup.

Deliverables:

- Running app shell.
- Base project files.
- Documented setup commands.

## Phase 2.2 - Confirm App Router Architecture

Tasks:

- Define App Router route groups and page ownership.
- Confirm server component, client component, API route, and server action boundaries.
- Define environment variable requirements.

Deliverables:

- Route architecture plan.
- Environment variable checklist.

## Phase 2.3 - Create Shared Types and Foundation Modules

Tasks:

- Add tax knowledge TypeScript types.
- Add shared source, review status, chat response, and query interpretation types.
- Create initial module boundaries for UI, data, backend, validation, and AI orchestration.

Deliverables:

- Shared type files.
- Initial module folders.
- Architecture notes updated if implementation reveals changes.
