Objective: Establish project rules, structure, documentation, and shared understanding before coding.

## Phase 1.1 - Define Project Requirements

Tasks:

- Finalize core project requirements.
- Define users, goals, boundaries, and primary use cases.
- Create modular project documentation.
- Organize documentation into categorized folders.

Deliverables:

- Root `AGENT.md`.
- `docs/agent/REQUIREMENTS.md`.
- `docs/agent/RULES.md`.
- `docs/agent/DECISIONS.md`.
- Phase, workflow, skills, structure, and logs folders.

Tasks:

- Confirm Next.js full-stack architecture.
- Define frontend, backend, tax data, search, chat, validation, and documentation modules.
- Confirm module boundaries and file responsibilities.

Deliverables:

- Complete structure guidance under `docs/structure/`.
- Confirmed module boundaries.

## Phase 1.3 - Define Data and Source Policy

Deliverables:

- Data model guidance in `docs/structure/BACKEND_STRUCTURE.md`.

## Phase 1.4 - Validate Planning System Before Implementation

Tasks:

- Confirm all required phase, workflow, skill, structure, and log files exist.
- Check that `AGENT.md` references only valid documentation paths.
- Identify missing planning coverage before app scaffolding begins.
- Record meaningful documentation improvements in `docs/logs/IMPROVEMENTS.md`.

Deliverables:

- Complete phase index from planning through maintenance.
- Workflow coverage for pages, CRUD, UI, research, content validation, database, API, and deployment.
- Skill coverage for research, validation, content writing, anti-hallucination, UI consistency, database planning, and architecture thinking.
