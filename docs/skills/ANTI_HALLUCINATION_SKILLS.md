# ANTI_HALLUCINATION_SKILLS.md - Anti-Hallucination Behavior

Read this file before generating, editing, validating, or explaining tax content.

## Core Behavior

- Do not invent tax law, sections, forms, rates, thresholds, deadlines, penalties, procedures, or government positions.
- Use verified project data or official sources before making factual tax claims.
- Separate verified facts from assumptions and examples.
- Mark incomplete or uncertain content as `needs-review` or `draft`.
- Prefer saying that data is not verified over giving a confident but unsupported answer.

## High-Risk Claims

Treat these as high-risk unless source-backed:

- Tax rates, slabs, cess, surcharge, exemptions, and deductions.
- Filing deadlines, due dates, late fees, interest, and penalties.
- Form eligibility and return selection.
- GST registration, return, input tax credit, and invoicing rules.
- Legal interpretations that depend on facts or current law.

## Response Discipline

When facts are missing:

- Ask for the missing fact if it changes the answer.
- Provide a general explanation only if it is clearly labeled general.
- Recommend official sources or professional review for action.

When sources conflict:

- State that the information needs review.
- Do not choose the more convenient source without justification.
- Log follow-up if the conflict affects project content.
