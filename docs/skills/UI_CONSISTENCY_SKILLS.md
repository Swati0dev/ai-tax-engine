# UI_CONSISTENCY_SKILLS.md - UI Consistency Behavior

Read this file before designing or reviewing pages, layouts, components, and interactions.

## UI Principles

- Prioritize readability, spacing, accessibility, and trust.
- Keep the interface professional, modern, and calm.
- Use reusable components for repeated tax patterns.
- Avoid clutter, decorative overload, and overly technical presentation.
- Make review status, caveats, and source links easy to find.

## Consistency Checks

- Navigation labels must match across pages.
- Direct Tax, Indirect Tax, GST, Forms, Sources, and Chat should use consistent hierarchy.
- Cards, badges, source blocks, and related links should behave consistently.
- Empty, loading, error, disabled, and needs-review states should be designed intentionally.
- Text must remain readable on mobile and desktop.

## UI UX Pro Max Pre-Delivery Checklist

- [ ] **No Emojis as Icons**: Use SVGs (Lucide/Heroicons) exclusively.
- [ ] **Interactive Cursors**: Ensure `cursor-pointer` is on all clickable elements.
- [ ] **Smooth Transitions**: Hover states must use `150-300ms` transitions.
- [ ] **Text Contrast**: Maintain a minimum 4.5:1 ratio (WCAG AA).
- [ ] **Focus States**: Ensure focus rings are visible for keyboard navigation.
- [ ] **Responsive Flow**: Verify layout at 375px, 768px, 1024px, and 1440px.

## Accessibility Checks

- Use semantic headings.
- Maintain sufficient contrast.
- Keep keyboard navigation practical.
- Ensure buttons and links have clear names.
- Avoid hiding critical caveats or source status behind decorative UI.
